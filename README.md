# Blackjack

A Java Blackjack game I made in high school while learning object-oriented programming.

I kept the original code and comments, including feedback from my teacher, because I wanted to preserve the project as I originally made it.

The game supports multiple players, betting, card drawing, a dealer, and basic Blackjack win and loss logic.

## Features

* Multiple players
* Randomly shuffled deck
* Hit or stay decisions
* Betting system
* Dealer turns
* Blackjack and bust detection

## What I learned

* Creating and using Java classes
* Working with `ArrayList`
* Object-oriented programming
* User input with `Scanner`
* Breaking game logic into separate classes
* Managing game state across multiple rounds
